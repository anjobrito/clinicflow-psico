# Nota de risco pré-comercial

A versão atual é apropriada para demonstração e validação comercial inicial.

O risco principal é confundir MVP demonstrativo com produto pronto para dados reais. Para evitar isso, a comunicação deve deixar claro que:

- o fluxo já representa o produto desejado;
- a interface já permite demonstração;
- as regras principais já estão desenhadas;
- a próxima fase técnica é backend, banco e segurança;
- nenhum dado real de paciente deve ser usado antes dessa fase.
