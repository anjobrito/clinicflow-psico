# Limitações atuais do MVP

- Persistência local no navegador.
- Sem login real.
- Sem backend de autorização.
- Sem isolamento físico de dados por cliente.
- Sem backup.
- Sem monitoramento.
- Sem política LGPD final.
- Sem integração fiscal real.
- Sem assinatura digital de documentos.

Essas limitações não impedem demonstração comercial, mas impedem uso com dados reais.
