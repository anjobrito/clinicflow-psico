# Business readiness

## Posicionamento atual

O produto está próximo de uma versão demonstrável para prospecção comercial, mas ainda não está pronto para operar com dados reais.

## Pode ser usado para

- Apresentação comercial.
- Validação com usuários internos.
- Demonstração de fluxo.
- Discussão de proposta com clínicas.
- Comparação funcional com sistemas legados.

## Não deve ser usado ainda para

- Cadastro real de pacientes.
- Armazenamento de evolução clínica real.
- Emissão oficial de documentos psicológicos.
- Controle financeiro oficial.
- Operação com múltiplos clientes reais.

## Próximo investimento técnico

Banco real + autenticação + autorização backend.
