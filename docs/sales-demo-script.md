# Roteiro de demonstração comercial

## Preparação

1. Abrir `/reset`.
2. Digitar `RESETAR`.
3. Executar reset.
4. Abrir `/`.

## Demonstração sugerida

1. Mostrar dashboard e agenda.
2. Criar ou abrir uma consulta.
3. Mostrar evolução clínica.
4. Abrir documentos psicológicos.
5. Mostrar usuários e diferença entre psicólogo e secretária.
6. Mostrar consultórios/unidades.
7. Mostrar financeiro.
8. Mostrar relatórios.
9. Mostrar auditoria.
10. Abrir AJB Admin e bloquear licença.
11. Mostrar produto bloqueado.
12. Voltar ao reset e restaurar demonstração.

## Mensagem comercial

ClinicFlow Psico é um SaaS de gestão para psicólogos e clínicas, com controle AJBNetSystems, licença, multi-consultório, gestão de usuários, documentos, financeiro e auditoria.

## Observação honesta

A versão atual é demonstrativa. Para clientes reais, a próxima fase precisa ativar banco real, login e permissões no backend.
